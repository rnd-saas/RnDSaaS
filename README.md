# RnDSaaS
General information about the project:
- This is the repository for a fintess SaaS application for students with social anxiety

How to run the project locally:
- make sure node.js is installed (at least v18)
- open the frontend folder in your command prompt and run:
  npm run dev

How to contribute to the project:
- The main branch should always be deployable, use new branches for new features
